# 目的と概要（検証用プロトタイプ）
C++23で構築した動的木構造（VarNode）および汎用RepositoryフレームワークをJavaへ移植し、さらに
「Project Panama（Foreign Function & Memory API）」を用いたC++版とのバインディングによる
実行速度・パフォーマンスの比較検証を試みたR&D（研究開発）用のプロトタイプコードです。

検証結果として、Spring Dataが構築する巨大なエコシステムと最適化の壁を実感するに至りましたが、
低レイヤ言語とJavaの相互運用、およびフレームワーク抽象化の限界値を測定する目的でコードを公開しています。
